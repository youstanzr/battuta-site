# Battuta — website

The website of Battuta, a geography quiz for iPhone and iPad: a landing page, a support page and
a privacy policy, in ten languages.

| Address | Page |
| --- | --- |
| `index.html` | Landing page |
| `support.html` | Support |
| `privacy.html` | Privacy policy |

English is at the top of the site. Every other language has the same three pages in a folder named
by its code: `ar/`, `de/`, `es/`, `fr/`, `it/`, `ja/`, `ko/`, `pt/`, `tr/`. `img/` holds the pictures.
